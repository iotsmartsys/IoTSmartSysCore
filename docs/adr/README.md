# Decisões arquiteturais

Este diretório recebe ADRs locais criadas quando uma decisão cruza
especificações ou componentes, estabelece fronteira ou direção de dependência,
impõe restrição durável, envolve trade-off material ou substitui decisão
arquitetural anterior.

ADRs seguem o template e as guardas do EKOM 4.6. Somente o Arquiteto aceita uma
decisão arquitetural; relatórios podem recomendar, mas não promovem uma ADR.
