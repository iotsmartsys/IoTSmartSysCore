## Resultado material

- criado `INA3221Device`, com uma instância Adafruit, `TwoWire&`, configuração
  pública, setup idempotente e falhas globais observáveis;
- criados `INA3221VoltageSensor` e `INA3221CurrentSensor`, com configurações
  copiadas, snapshots estáveis, cadência cooperativa, rollover, estados de
  faixa, shunt, polaridade e calibração não aplicável;
- adicionados overloads externos de `SmartSysApp` e `CapabilitiesBuilder`, sem
  ownership ou arena de adapters e sem reserva de GPIO;
- preservadas as APIs e implementações ACS712-30A e divisor resistivo;
- declarado `adafruit/Adafruit INA3221 Library@^1.0.3` em `library.json`;
- criado o exemplo combinado `ina3221_voltage_current`, environment, seletor,
  catálogo e README de montagem e segurança.

## Decisões locais

- tipos públicos INA3221 ficaram junto aos adapters em
  `src/Platform/Arduino/Sensors/` e são agregados por `SmartSysApp.h` quando
  sensores estão habilitados;
- o dispositivo recusa uma segunda resistência diferente no mesmo canal;
- o exemplo limita `maximumAbsoluteCurrentA` a `1,500 A`, abaixo do limite
  teórico de `1,638 A`, com deadband de `0,005 A` e mínimo reportável de
  `0,010 A`.

## Evidências de build

- `pio run -e example_ina3221_voltage_current_mcb_r1`, com o manifesto
  normativo: `FAILED`, código 1. O PlatformIO informa `UnknownPackageError`
  porque não encontra `adafruit/Adafruit INA3221 Library@^1.0.3`;
- `pio pkg show --type library "adafruit/Adafruit INA3221 Library"`: o registro
  oferece somente `1.0.1`, publicada em 22/10/2024;
- build diagnóstico do mesmo environment, substituindo temporariamente apenas
  a origem pela tag oficial Git `1.0.3` no commit
  `43558800d999eecb35de7b15b94488afa945825e`: `SUCCESS`, código 0, 30,188 s,
  RAM 68.908/327.680 bytes e flash 1.182.157/2.031.616 bytes. O manifesto
  normativo foi restaurado depois da execução;
- `pio run -e esp32_dev`: `FAILED`, código 1, 14,591 s. Todos os novos objetos
  INA3221 compilaram; a falha posterior ocorre em `src/main.cpp` por símbolos
  MCB R1 ausentes no target genérico e pelo enum `TemperatureSensorModel::DS18B20`,
  limitações preexistentes e fora do delta.

## Lacuna e impacto

INA-044, INA-045 e INA-AC-006 exigem resolução limpa pelo nome de registro e
versão `^1.0.3`. Essa versão existe no repositório Git oficial, mas não no
registro PlatformIO consultado; portanto o build canônico do exemplo e o
critério de consumidor limpo são insatisfazíveis no contrato corrente. Trocar
para a tag Git, aceitar `^1.0.1` ou aguardar publicação altera a decisão
normativa e permanece reservado ao Arquiteto.
