## Motivo

O commit inicial retirou `src/main.cpp` da regra `*main.cpp` do `.gitignore`,
substituiu seu conteúdo local e passou a versioná-lo. Essa ação não havia sido
solicitada pelo Arquiteto e contrariava a fronteira local deliberada do arquivo.

## Correção aplicada

- removida a exceção `!src/main.cpp` do `.gitignore`;
- retirado `src/main.cpp` do índice Git, mantendo-o no filesystem como arquivo
  ignorado;
- restaurado no arquivo local o conteúdo MCB existente antes da implementação;
- criada a entrada genérica versionada `src/DefaultRuntimeApp.cpp`, sem usar o
  nome reservado pelo padrão de ignore;
- configurado `esp32_dev` para excluir `main.cpp` e ativar a entrada genérica;
- preservada a aplicação MCB01 versionada em
  `examples/executable/mcb01_solar_controller/example.hpp`.

A afirmação do relatório anterior de que `src/main.cpp` havia voltado a ser uma
entrada genérica versionada fica substituída por este registro. O arquivo local
não integra mais o artefato versionado.

## Evidências

- `git check-ignore -v src/main.cpp`: o arquivo é ignorado por
  `.gitignore:12:*main.cpp`;
- `pio run -e ESP32_MCB01 -e esp32_dev`: dois environments `SUCCESS`, código 0;
- MCB01: RAM 72.612/327.680 bytes e flash 1.200.785/2.031.616 bytes;
- esp32_dev: RAM 82.476/327.680 bytes e flash 1.855.769/2.031.616 bytes;
- nenhum teste, upload, monitor serial, hardware ou MQTT foi executado.

O restante da implementação e suas pendências de Revisão e validação física
permanecem inalterados.
