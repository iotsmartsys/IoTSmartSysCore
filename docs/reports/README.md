# Relatórios EKOM

Relatórios registram fatos, achados e evidências de uma atuação; não criam
requisitos. Os arquivos históricos na raiz deste diretório permanecem
imutáveis.

Novas atuações usam registros separados para análise de implementabilidade,
implementação, revisão e validação. Cada execução cria um arquivo novo conforme
os templates e a nomenclatura do EKOM 4.6; correções usam adendo ou novo
relatório relacionado.
